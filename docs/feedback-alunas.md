# Feedback das alunas (backlog)

Pedido do Bruno (30/10/2026): sem esses feedbacks não dá para melhorar o app. Aqui entra o que as alunas dizem
(sugestão, reclamação, dúvida que se repete) para virar ajuste. Uma linha por item: o que, quantas vezes, de quem
(só o primeiro nome), data e estado (`novo`, `decidido`, `feito`, `descartado`). Decisão de produto é do Bruno.
As conversas ficam em `whatsapp_messages`; a revisão semanal (ver `revisao-conversas-whatsapp` na memória) puxa os
itens novos para cá.
